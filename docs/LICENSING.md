# Licensing and provenance - unresolved release gate

No project-wide redistribution license is selected by this change. The previous README
states that the prototype was prepared after studying Atomicx7/Duo-animation and that
upstream licensing was not confirmed. That historical statement has not been verified here.

Before distribution, the owner must review file provenance, obtain any needed upstream
permissions or replace affected material, choose the intended project license, and record
its actual copyright holders. Do not invent an SPDX grant or mark this review complete.

Dependencies and bundled tooling retain their own licenses. Review notices for Kotlin,
Compose/Skia/Skiko, AndroidX, kotlinx.coroutines and Gradle Wrapper against the resolved
artifacts. Gradle Wrapper files retain their generated license headers. Development tools
under .tools are excluded from distribution. Maven staging is local only; it is not a public
release. Fill license and project URLs in POM metadata only after ownership is confirmed.
